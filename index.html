How it works: the Four Laws

Small habits, repeated, become who you are. Each tick is a vote for the person you want to be. Based on Atomic Habits by James Clear.

Law Build a good habit Break a bad habit
1. CueMake it obviousMake it invisible
2. CravingMake it attractiveMake it unattractive
3. ResponseMake it easyMake it difficult
4. RewardMake it satisfyingMake it unsatisfying
  • Cue: attach the habit to something you already do.
  • Identity: state who you are becoming, so each tick is a vote for it.
  • 2-Minute Rule: start with a version so small you can't say no.
  • Never miss twice: one miss is fine; do the tiny version the next day.
  • Reward: give yourself an immediate, small reward, even just ticking it off.
